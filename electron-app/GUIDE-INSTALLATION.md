# Guide d'Installation - Le Paradisier Manager

## Installation du logiciel

### Étape 1 : Lancer l'installation
1. Double-cliquez sur le fichier **Le-Paradisier-Manager-Setup-2.0.0.exe**
2. Si Windows affiche un avertissement, cliquez sur **"Plus d'infos"** puis **"Exécuter quand même"**

### Étape 2 : Suivre l'assistant
1. Lisez et acceptez la licence d'utilisation
2. Choisissez le dossier d'installation (par défaut : C:\Program Files\Le Paradisier Manager)
3. Cliquez sur **"Installer"**
4. Attendez la fin de l'installation

### Étape 3 : Lancer l'application
- Double-cliquez sur l'icône **"Le Paradisier Manager"** sur votre bureau
- Ou recherchez "Le Paradisier Manager" dans le menu Démarrer

---

## Première connexion

### Mot de passe initial
- **Mot de passe par défaut :** `paradisier2024`

### Changer le mot de passe (IMPORTANT)
1. Connectez-vous avec le mot de passe initial
2. Allez dans **Paramètres** (icône engrenage)
3. Dans la section **"Sécurité"**, cliquez sur **"Changer le mot de passe"**
4. Entrez l'ancien mot de passe
5. Entrez votre nouveau mot de passe (2 fois)
6. Cliquez sur **"Enregistrer"**

> ⚠️ **IMPORTANT :** Notez votre nouveau mot de passe dans un endroit sûr !

---

## Utilisation quotidienne

### Navigation
- **Tableau de bord** : Vue d'ensemble des réservations et statistiques
- **Réservations** : Gérer les réservations de chambres
- **Restaurant** : Gérer les commandes et le menu
- **Clients** : Base de données des clients
- **Paramètres** : Configuration de l'établissement
- **Sauvegarde** : Exporter/importer vos données

### Raccourcis clavier
- `Ctrl + E` : Exporter les données
- `Ctrl + I` : Importer les données
- `Ctrl + R` : Actualiser l'affichage
- `F11` : Mode plein écran
- `Ctrl + +` : Zoom avant
- `Ctrl + -` : Zoom arrière
- `Ctrl + 0` : Zoom normal

## Sauvegarde des données

### Pourquoi sauvegarder ?
Vos données sont stockées sur votre ordinateur. En cas de panne, vous pourriez tout perdre.
**Sauvegardez régulièrement !**

### Comment sauvegarder ?
1. Allez dans **Sauvegarde** (menu de gauche)
2. Cliquez sur **"Exporter les données"**
3. Un fichier JSON sera téléchargé
4. Copiez ce fichier sur une clé USB ou dans le cloud

### Comment restaurer ?
1. Allez dans **Sauvegarde**
2. Cliquez sur **"Importer les données"**
3. Sélectionnez votre fichier de sauvegarde
4. Confirmez la restauration

> 💡 **Conseil :** Sauvegardez au moins une fois par semaine sur une clé USB.

---

## Dépannage

### L'application ne s'ouvre pas
1. Redémarrez votre ordinateur
2. Réinstallez l'application

### J'ai oublié mon mot de passe
1. Désinstallez l'application
2. Réinstallez-la
3. Utilisez le mot de passe initial : `paradisier2024`
> ⚠️ Attention : Cela supprimera toutes vos données !

### L'écran est trop petit/grand
- Utilisez `Ctrl + +` ou `Ctrl + -` pour ajuster le zoom
- Ou `Ctrl + 0` pour revenir à la taille normale

### Les données ont disparu
1. Vérifiez que vous êtes bien connecté
2. Si vous avez une sauvegarde, restaurez-la via **Sauvegarde > Importer**

---

## Désinstallation

1. Ouvrez le **Panneau de configuration** Windows
2. Cliquez sur **"Désinstaller un programme"**
3. Trouvez **"Le Paradisier Manager"**
4. Cliquez sur **"Désinstaller"**
