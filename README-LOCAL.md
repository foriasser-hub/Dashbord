# 🌴 Le Paradisier Manager - Application Locale

**Application de gestion hors-ligne** pour hôtels, restaurants et appartements meublés.

> Comme Excel, mais en mieux ! Interface professionnelle, données sécurisées, fonctionne sans internet.

---

## 📦 Installation

### Option 1 : Ouvrir directement (le plus simple)

1. Décompressez le fichier ZIP
2. Ouvrez le fichier `index-local.html` avec votre navigateur (Chrome, Firefox, Edge)
3. C'est prêt !

### Option 2 : Installer comme application (recommandé)

1. Ouvrez `index-local.html` dans Chrome ou Edge
2. Cliquez sur le bouton **"Installer"** dans la barre d'adresse ou dans l'application
3. L'application s'installe sur votre ordinateur/téléphone
4. Vous pouvez maintenant l'ouvrir comme n'importe quelle application

---

## 💾 Sauvegarde des données

**IMPORTANT** : Vos données sont stockées dans votre navigateur. 

### Faire une sauvegarde

1. Allez dans **Sauvegarde** (menu de gauche)
2. Cliquez sur **"Télécharger la sauvegarde"**
3. Un fichier JSON sera téléchargé
4. **Gardez ce fichier précieusement !**

### Restaurer une sauvegarde

1. Allez dans **Sauvegarde**
2. Cliquez sur **"Choisir un fichier"**
3. Sélectionnez votre fichier de sauvegarde `.json`
4. Confirmez la restauration

### Quand sauvegarder ?

- ✅ Chaque soir après le travail
- ✅ Avant de mettre à jour le navigateur
- ✅ Avant de changer d'ordinateur
- ✅ Une copie sur clé USB chaque semaine

---

## 🔑 Changer le mot de passe

1. Allez dans **Paramètres** (menu de gauche)
2. Section "Sécurité"
3. Entrez l'ancien mot de passe
4. Entrez le nouveau mot de passe (minimum 6 caractères)
5. Confirmez et enregistrez

## ❓ Questions fréquentes

### Mes données sont-elles sécurisées ?

Oui. Vos données sont stockées localement dans votre navigateur et ne sont jamais envoyées sur internet.

### Que se passe-t-il si je vide le cache du navigateur ?

**Vos données seront perdues !** C'est pourquoi il est essentiel de faire des sauvegardes régulières.

### Puis-je utiliser l'application sur plusieurs ordinateurs ?

Oui, mais les données ne se synchronisent pas automatiquement. Vous devez :
1. Exporter la sauvegarde sur l'ordinateur 1
2. Importer la sauvegarde sur l'ordinateur 2

### L'application fonctionne-t-elle sans internet ?

Oui ! Une fois installée, l'application fonctionne 100% hors-ligne.

### Comment mettre à jour l'application ?

1. Téléchargez la nouvelle version
2. Faites une sauvegarde de vos données
3. Remplacez les fichiers
4. Importez votre sauvegarde

## 🆘 Support

En cas de problème :
1. Vérifiez que vous avez bien fait une sauvegarde
2. Essayez de vider le cache du navigateur et réimporter votre sauvegarde
3. Testez avec un autre navigateur (Chrome recommandé)
