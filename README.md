# 🌴 Le Paradisier Manager

**Mini logiciel professionnel de gestion pour restaurant & appartements meublés.**

![Version](https://img.shields.io/badge/version-1.0-green)
![License](https://img.shields.io/badge/license-MIT-blue)

## 🎯 Présentation

Le Paradisier Manager est un outil de gestion tout-en-un conçu pour centraliser la gestion complète d'un établissement combinant restaurant, hébergement et livraisons.

## ✨ Fonctionnalités

| Module | Description |
|--------|-------------|
| 📊 Tableau de bord | Vue globale KPI, graphiques, alertes |
| 📅 Réservations | Gestion complète des réservations chambres/appartements |
| 🏨 Chambres & Appartements | Gestion des unités, statuts, équipements |
| 🍽️ Restaurant | Commandes, statuts, paiements |
| 🛵 Livraisons | Suivi livreurs, statuts, encaissements |
| 👥 Clients | Mini CRM avec historique et WhatsApp |
| 📦 Stock | Inventaire, alertes seuil, valorisation |
| 💸 Dépenses | Suivi par catégorie et fournisseur |
| 💰 Finances | Bilan complet, graphiques, paiements en attente |
| 👔 Personnel | Présence, tâches, planning |
| 📈 Rapports | Export CSV, impression, copie résumé |
| ⚙️ Paramètres | Configuration, export/import JSON, réinitialisation |

## 🛠️ Technologies

- HTML5, CSS3, JavaScript vanilla
- Chart.js (graphiques)
- localStorage (persistance données)
- PWA (mode hors-ligne)
- Responsive design

## 📱 Installation locale

1. Cloner le dépôt
2. Ouvrir `index.html` dans un navigateur
3. L'application fonctionne immédiatement avec des données de démonstration

## 🎨 Design

- Style luxe hôtelier tropical
- Palette : vert sarcelle profond, doré, ivoire
- Police : Poppins
- Responsive mobile/desktop
- Interface premium

## 📋 Utilisation

- Naviguer entre les modules via la sidebar
- Ajouter/modifier/supprimer des éléments dans chaque module
- Les données sont sauvegardées automatiquement dans le navigateur
- Exporter en JSON depuis Paramètres pour sauvegarder
- Exporter en CSV depuis Rapports
